Document Inbox – Scanner & File Upload Setup

Just scan and walk away. The watcher program reads each document using OCR (optical character recognition), identifies the member automatically from names or ID numbers on the page, detects the document type, and uploads it to the correct member's file cabinet. No manual file naming required.

📁 Step 1 — The Inbox Folder

All scanned documents and files go into this one folder:

C:\Users\rmars\OneDrive\Documents\Documents\marsliz\Horizon-House\Members\_inbox

Inside that folder you will also find:

📄 START WATCHER - double click me.bat
Double-click this file to start the auto-uploader. Keep the window open while you work.

📂 processed\ — Files that uploaded successfully are moved here automatically.
📂 review\ — Files the system could not identify go here. A .ocr.txt file is saved next to each one showing exactly what was read from the page.

🤖 Step 3 — How OCR Identification Works

The watcher automatically reads each scanned document and identifies the member. You do not need to rename files.

What the software looks for (in order):

1. Member ID number — if the filename or the document contains a 2–4 digit member ID (e.g. 0133, 160), it matches that member.

2. Full member name — OCR reads the text on the page and looks for a member's first and last name together.

3. Last name only — if only a last name is found, it still routes it (flagged as low-confidence so you can verify).

4. Document type — OCR also detects the type automatically: Drug Screen, Agreement, Incident Report, Court Document, etc.
💡 Optional — speed things up: If you include the member ID anywhere in the filename, the OCR step is skipped and the file routes instantly. Example: 0133 Scan001.pdf

▶️ Step 4 — Start the Watcher & Scan

1
Double-click START WATCHER - double click me.bat inside the inbox folder. A black window opens — this is the uploader running.
2
Scan your documents (or copy files into the inbox folder). The watcher checks every 10 seconds.
3
Watch the black window — you'll see "SUCCESS: Uploaded to [Member Name]'s file cabinet" for each file.
4
Processed files move to the processed subfolder. Unidentified files go to review with a .ocr.txt note.
5
When done, close the black window (or press Ctrl+C).
